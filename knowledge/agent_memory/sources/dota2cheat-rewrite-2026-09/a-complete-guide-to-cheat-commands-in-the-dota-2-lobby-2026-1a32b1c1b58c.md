**Dota 2 lobby cheat commands** are built-in practice tools. They work in a private lobby configured to allow cheats; they are not third-party software and they do not transfer into ordinary matchmaking. Use them to reproduce a lane state, test damage, practice a combo or verify an item interaction.

The command set changes over time, so use autocomplete and current community documentation when an old spelling no longer works.

## Create a private practice lobby

1.   Open Play and create a custom lobby.
2.   Choose Local Host when required by the current client.
3.   Enable cheats in the lobby settings.
4.   Add bots or a friend if the drill needs another unit.
5.   Start the match and enter supported chat commands.

The [maintained Dota 2 practice-command reference](https://liquipedia.net/dota2/Cheats) distinguishes lobby cheat commands from third-party modifications and lists current equivalents.

## Gold, levels and item testing

Use the gold and level commands to reach a planned timing without playing an entire match. Item commands can build a specific inventory for damage or survivability tests. Record the hero level, talents, items and target armor so a later run is comparable.

A good drill changes one variable at a time. If you add levels, items and neutral bonuses together, you will not know which change produced the result.

## Cooldown, health and mana resets

Refresh and respawn commands shorten repetition. Test the same spell sequence from the same position, reset resources, then run it again. Unlimited-mana or no-cooldown modes are useful for learning order and range, but turn them off before testing realistic timing.

Practice first at normal speed. A drill that only works with artificial cooldowns can create habits that fail in a real match.

## Spawn heroes and controlled targets

Create an enemy or allied hero to test interactions that Demo Hero does not make convenient. Add items and levels to the target, then repeat the setup. Hero internal names can differ from display names, so console autocomplete helps when a command rejects a name.

## Vision and map-state drills

Vision toggles can help review ward lines and spell ranges inside the controlled lobby. Creep-spawn and game-start controls can reproduce lane timing faster. These tools are valuable because the environment is explicit and consensual.

Do not confuse all-vision practice with a maphack in matchmaking. One is a lobby option enabled by the host; the other claims access to information ordinary players should not receive.

## Turn commands into a repeatable routine

*   Write the starting state in one short checklist.
*   Run five to ten repetitions with one goal.
*   Reset to the same health, mana and position.
*   Record failures, not only the fastest attempt.
*   Finish with normal cooldowns and visibility.

## Example practice sessions

For last-hit practice, lock the hero, level and starting items, keep normal creep timing and record results over several waves. For combo practice, spawn the same target with the same defensive items, reset resources and increase complexity only after the basic order is reliable.

For ward testing, place the observer from both high and low ground, move the target through the edge of vision and record which terrain blocks the line. For a spell interaction, change one resistance or immunity source per run. Commands save setup time; disciplined variables turn that time into useful evidence.

End each session by repeating the drill without artificial vision, unlimited mana or cooldown removal. The final run tests whether the learned sequence transfers to ordinary conditions.

Name saved drills by hero, goal and patch so you can discard stale assumptions later. When an ability or item is reworked, rebuild the setup rather than forcing old numbers into the new version. Practice commands are most valuable when the scenario is reproducible and the conclusion has a date.

Keep commands inside the lobby where cheats were enabled. If a protected command is rejected elsewhere, that is expected behavior—not a reason to install a third-party tool.
