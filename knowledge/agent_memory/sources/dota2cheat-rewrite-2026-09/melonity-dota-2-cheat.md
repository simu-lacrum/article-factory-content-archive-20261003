## Hero scripts and visual tools

Hero modules can expose target priorities, item order, ability conditions and defensive reactions. A useful product page explains what happens when a target disappears, an ability is unavailable or a higher-priority target appears. Without that detail, configuration depth is difficult to judge.

Visual modules may show ranges, cooldowns, statuses or map-related alerts. Distinguish information already visible in the client from claims about concealed data, and ask the provider which modules are enabled for the current build.

## Setup and access questions

Before creating an account, confirm the supported Windows version, the current Dota build, whether access begins at purchase or first activation, and the provider’s download channel. The plan should state duration, currency, final price and what happens during a patch-related pause. Do not infer these details from a video.

Never send Steam credentials, browser cookies or recovery codes to a provider. If an executable asks for broad administrator access or a permanent security exception without an explanation, stop and ask support through the authenticated channel.

## Keep evidence separate from assumptions

An interface screenshot proves that a control was displayed at one moment. It does not prove that the control is enabled for every hero, that its data is current, or that the product is available on the build you are running. Treat each screenshot as a prompt for a live-listing question.

Support answers should be specific enough to save. Ask for the supported build, required Windows version, activation sequence and documented removal path. A clear “not supported right now” is more useful than a broad “everything works” reply. Save the answer with the date because a patch can invalidate it.

Check the boundary between account access and system access. The Melonity account should handle plan and download information; it should not require a Steam login. An installer should identify what it changes and how to undo it. These checks make onboarding easier to review without turning this article into an unverifiable endorsement.
