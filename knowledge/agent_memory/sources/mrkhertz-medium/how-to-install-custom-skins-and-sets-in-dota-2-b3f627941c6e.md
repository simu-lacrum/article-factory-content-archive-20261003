## Manual installation of vpk files into game files

This method involves digging through game files and searching for vpk skin files. You can find them in a variety of places — Telegram channels, websites, and other resources.

Of course, installation is **at your own risk**. I won’t name any specific sites where you can find them, so I recommend searching for them yourself on Google if you’ve decided to go ahead with it.

There are three main methods, which are described in one way or another in the places where they are distributed.

### 1. Manually

To do this, you need to:

1.   Download the archive.
2.   Find the game folder in Steam — Browse -> Installed Files -> Browse.
3.   Extract the contents of the archive into the game folder, replacing the files.

### 2. Automatic (.bat)

To simplify the installation process, many skilled users create scripts using .bat files, which perform the same actions, but automatically.

I would like to emphasize once again that you do this entirely at your own risk, as you can never know for sure what is inside all these archives and files. If something happens, there will be no one to turn to, as there will be no legal entity or any contact information provided, unlike skinchangers such as MetaSkins.

1.   Unzip the downloaded archive into any folder.
2.   Run the .bat file from the same folder.
3.   If Windows Defender blocks the launch: click “More details” → “Run anyway.”
4.   After installation, Dota will launch automatically

### 3. VPK Manager

1.   Download and open the VPK Manager program
2.   Drag the archive downloaded with skins directly into the program window.
3.   Click the “Install” button in the application.
