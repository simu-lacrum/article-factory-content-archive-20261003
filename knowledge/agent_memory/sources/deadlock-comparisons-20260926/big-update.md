Markdown Content:
The biggest update in the history of the project. It brings a **new renderer**, a **new menu** and unlimited customisation. **~95% of the functionality** has been rewritten or touched in some way.

The update covers all of our games. For now you can only try it in Deadlock — over the coming week we plan to retire every older version, leaving only the new one.

[Video 10](https://octarinecore.cc/assets/images/blog/big-update/menu-tour.mp4)
*   Absolutely every element can be changed.
*   The menu resizes however suits you: make it compact so it doesn't cover objects or get in the way while you set things up. Every element inside adapts to the new size automatically.
*   The main menu can sit on top, to the side, be hidden, or be given a size of its own.
*   Endless themes: you can set up different ones for the world, the panels or the menu itself.

## What we reworked

Almost every feature has been reworked and improved. Here are the main changes.

[Video 11](https://octarinecore.cc/assets/images/blog/big-update/rejuvenator.mp4)
### 3D preview

The preview shows every visual — right down to Glow — and it was built not just for heroes, but for most features, visual and otherwise.

Any element can be moved wherever you like. We even made it possible to pin an element straight onto the in-game health bar.

![Image 8: The ESP preview panel: a player model with health bars, buffs, distance and item value](https://octarinecore.cc/assets/images/blog/big-update/esp-preview-players.webp)![Image 9: Visual → Creatures → Trooper boss: a boss preview with Glow switched on](https://octarinecore.cc/assets/images/blog/big-update/esp-preview-boss.webp)![Image 10: Aimbot → Creeps → Walker: an aim preview with bones and the selected aim point](https://octarinecore.cc/assets/images/blog/big-update/esp-preview-aim.webp)

### Custom chams

Chams are a rarity in Deadlock — almost everyone uses Glow instead. We wrote our own engine that can apply any material.

Plenty of ready-made presets, a theme generator, and Blur and Glow effects.

### Dodger

It now includes Auto parry, anti-parry and dodging with items and abilities.

![Image 11: The Dodger panel: a list of abilities to cancel — Counterspell, Sanguine Retreat, Dispel Magic, Ethereal Shift, Return to Shadows and Unstoppable — with toggles, next to a grid of Abilities icons](https://octarinecore.cc/assets/images/blog/big-update/dodger-panel.webp)
