## Aimbot

Category: aim assistance.

Key functions:

- Fov: aim-assist capture radius around the crosshair.
- Smooth: controls how gradual aim movement feels.
- Auto Pistol: repeated-fire comfort feature for semi-automatic pistols.
- Fov Color: visual color of the FOV indicator.
- Target priority: chooses targets by crosshair distance or hit chance.
- Hitboxes: Head, Neck, Spine, Hips, Arms, Legs.
- Checks: Visible, Team, Flash.
- Weapons: separate settings/profiles by weapon type.

## TriggerBot

Category: shot timing assistance.

Key functions:

- Hitboxes: Head, Neck, Spine, Hips, Arms, Legs.
- Checks: Visible, Team, Flash.
- Multipoint scale: conceptual precision/forgiveness setting for accepted points inside hitboxes.
- Reaction time: delay before assisted shot after a valid condition.
- Between-shots delay: delay between assisted shots.
- Minimum damage: damage threshold before triggering.
- Hit chance: estimated chance-to-hit threshold.
- Visualize multipoint hit: overlay showing valid target points.
