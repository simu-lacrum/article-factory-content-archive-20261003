## Visual information and utility tools

Visual modules may present ranges, cooldowns, status information or map-related alerts. Buyers should distinguish data already visible in the client from features that claim access to concealed information. The second category carries a clearer enforcement precedent.

Utility functions can reduce repeated interface work, but they should state triggers and exclusions. A generic “helper” label is not enough to judge either value or risk.
