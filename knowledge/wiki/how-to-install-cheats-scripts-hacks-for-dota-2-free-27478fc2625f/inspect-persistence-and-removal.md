## Inspect persistence and removal

A download should disclose whether it creates a service, startup entry, scheduled task, driver or network rule. If removal consists only of deleting the original archive, those components may remain. Record changes and require an uninstall path before testing.

Use an isolated, non-valuable environment for file analysis. Do not assume a virtual machine removes account or platform risk, and do not treat isolation as a way around anti-cheat.
