## Example practice sessions

For last-hit practice, lock the hero, level and starting items, keep normal creep timing and record results over several waves. For combo practice, spawn the same target with the same defensive items, reset resources and increase complexity only after the basic order is reliable.

For ward testing, place the observer from both high and low ground, move the target through the edge of vision and record which terrain blocks the line. For a spell interaction, change one resistance or immunity source per run. Commands save setup time; disciplined variables turn that time into useful evidence.

End each session by repeating the drill without artificial vision, unlimited mana or cooldown removal. The final run tests whether the learned sequence transfers to ordinary conditions.

Name saved drills by hero, goal and patch so you can discard stale assumptions later. When an ability or item is reworked, rebuild the setup rather than forcing old numbers into the new version. Practice commands are most valuable when the scenario is reproducible and the conclusion has a date.

Keep commands inside the lobby where cheats were enabled. If a protected command is rejected elsewhere, that is expected behavior—not a reason to install a third-party tool.
