## Create a private practice lobby

1.   Open Play and create a custom lobby.
2.   Choose Local Host when required by the current client.
3.   Enable cheats in the lobby settings.
4.   Add bots or a friend if the drill needs another unit.
5.   Start the match and enter supported chat commands.

The [maintained Dota 2 practice-command reference](https://liquipedia.net/dota2/Cheats) distinguishes lobby cheat commands from third-party modifications and lists current equivalents.
