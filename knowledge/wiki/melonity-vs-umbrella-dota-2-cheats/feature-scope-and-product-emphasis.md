## Feature scope and product emphasis

Melonity is commonly presented as a broad script platform with hero automation, visual information and utility modules. Umbrella is commonly presented through a more compact collection of core functions. Those descriptions should be checked against the live build because module names and supported heroes can change.

Count only functions that are explained. Ten named toggles inside one visual panel may represent less coverage than one well-documented hero module with clear configuration and exclusions.
