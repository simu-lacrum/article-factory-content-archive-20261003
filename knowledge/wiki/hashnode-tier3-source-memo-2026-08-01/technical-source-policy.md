## Technical source policy

UnknownCheats and similar forums can be used to discover vocabulary, recurring reader questions, and feature names. They are not authoritative for current detection status, anti-cheat architecture, safety, ban history, or implementation details. Do not cite operational bypass discussions.

Use primary sources for verifiable technical facts:

- Microsoft `Get-FileHash`: https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/get-filehash
- Microsoft `Get-AuthenticodeSignature`: https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.security/get-authenticodesignature
- Valve Developer Community, Dota custom-event listener: https://developer.valvesoftware.com/wiki/Dota_2_Workshop_Tools/Scripting/API/CCustomGameEventManager.RegisterListener
- Valve/Steam Support VAC overview: https://help.steampowered.com/en/faqs/view/571A-97DA-70E9-FF74
- Valve CS2 live-ban notes: https://store.steampowered.com/news/app/730/view/3702568031467145905
- Valve VacNet 3.0 limited-test notes: https://steamcommunity.com/games/CSGO/announcements/detail/6500469346429581892

Safe technical content may explain process boundaries, data-flow diagrams, event-driven systems, state machines, target selection concepts, UI information architecture, file integrity, signatures, hashes, configuration backups, and rollback planning.

Do not provide injection code, memory offsets, driver details, hooks, anti-cheat bypasses, evasion settings, exploit chains, signature rotation, HWID manipulation, or instructions to suppress security software.
