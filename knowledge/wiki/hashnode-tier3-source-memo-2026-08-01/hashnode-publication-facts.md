## Hashnode publication facts

Official Hashnode documentation confirms:

- The editor supports Markdown, code blocks, rich formatting, previews, subtitles, article tags, and per-article SEO title/description settings.
- The recommended cover image size is 1200 × 630 pixels.
- Drafts can be previewed for web desktop, web mobile, email desktop, and email mobile.
- Hashnode supports an Original URL/canonical field when republishing. These Tier-3 articles are original adjacent-angle posts, so they should not point their canonical URL to the Medium target.
- Tags help the post appear in relevant Hashnode feeds. Use four or five narrow tags rather than a broad tag dump.
