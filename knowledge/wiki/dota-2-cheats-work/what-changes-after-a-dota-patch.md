## What changes after a Dota patch

A patch can rename an item, change a cast range, alter an entity field, update rendering, or change what an input event looks like. That is why an old video proves only that an interface existed at the time of recording. Before launching a tool, check the date of the current status, the supported build and the provider’s update policy. If those details are missing, treat compatibility as unknown rather than assuming it.

Use the [Dota 2 cheat detection guide](https://dota2cheat.com/guides/dota-2-cheat-detection) for broader platform context, and compare terminology with our [Dota 2 scripts guide](https://dota2cheat.com/guides/dota-2-scripts-guide). The right question is not “does this list contain every feature?” but “can I verify the specific feature I need on the current build?”
