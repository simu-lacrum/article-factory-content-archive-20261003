## Why the data source changes feature scope

Fog-of-war, hidden wards and unseen actions are not ordinary client information. Modules built around concealed data carry a different account and compatibility profile from overlays that organize visible events. Treat the data source as a buying question: ask what the feature reads, how the status is updated and which limitations the provider documents.

![Image 4: Dota 2 cheat configuration with information modules](https://dota2cheat.com/assets/dota2/dota2-48c5243214a94c81798d25c1.webp)

Configuration depth depends on the feature’s data source and current build.
