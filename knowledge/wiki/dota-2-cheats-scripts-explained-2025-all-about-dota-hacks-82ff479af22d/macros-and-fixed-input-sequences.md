## Macros and fixed input sequences

A macro replays a predetermined input or sequence. It may press several keys with set delays, but it does not necessarily understand game state. Fixed timing is fragile when latency, cast points, disables or target movement change.

The [Dota 2 macro types and limitations guide](https://cheatsgaming.com/games/dota-2/dota-2-macros-download-and-better-options-e93789e42036) covers the difference between hardware profiles, simple binds and adaptive automation.
