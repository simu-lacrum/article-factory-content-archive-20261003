## Official bot scripting is a separate ecosystem

Valve introduced a scripting API for community-authored bots and allows creators to distribute those bots through the Workshop. The [official community-authored bots announcement](https://www.dota2.com/700/other/) places that API inside Dota's supported custom-content workflow.

If you want to learn development, follow our [Workshop-safe Dota 2 scripting path](https://cheatsgaming.com/games/dota-2/how-to-write-your-own-script-for-dota-2-on-any-hero-72043d903e1e) rather than treating a closed third-party loader as a development environment.
