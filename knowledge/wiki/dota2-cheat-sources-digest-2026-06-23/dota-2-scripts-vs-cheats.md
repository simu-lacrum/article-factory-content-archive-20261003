### Dota 2 Scripts vs Cheats

Imported terminology:

- A script is described as an individual function that automates, visualizes, or simplifies a game action.
- A cheat is described as the larger program/container that provides scripts, interface, launcher, and supporting systems.

This distinction is useful for SEO explainers, glossaries, FAQ sections, and comparison articles.
