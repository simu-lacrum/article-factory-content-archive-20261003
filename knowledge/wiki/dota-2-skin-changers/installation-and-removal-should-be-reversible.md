## Installation and removal should be reversible

Before opening an installer, record its publisher, version, supported Dota build and every path it says it will touch. Keep a copy of personal configuration separate from game files. An installer that hides its contents, creates unexplained startup services or asks for a Steam password is a reason to stop. Do not disable broad security controls just to make an unsigned program run.

Use the tool's documented uninstaller first. Then compare the changed paths with your notes and check for services, scheduled tasks or drivers. Steam file verification can restore supported game files, but it does not prove that every third-party component has been removed.
