## 4. Download only from the account

Use the download button or URL displayed after sign-in. Match the file name and version to the instructions. Avoid video-description links, reposted archives and “fix” executables offered in public chats. Save the order record and activation instructions before launching anything.

Close Dota 2 first. Record the folders, services or drivers the installer says it will add, and keep the removal instructions open. Do not disable security controls globally or create a permanent exception for an unexplained path. A broad administrator request without a clear reason is a stop signal.
