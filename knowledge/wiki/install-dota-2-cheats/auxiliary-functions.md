#### Auxiliary functions

These are all functions that automate game actions in one way or another, but do not belong to the two categories above.

**This includes:**

*   Last Hit: Automatically finishes off creeps and denaits allied creeps when there is only one hit left.
*   Auto Stop: Automatically stops creeps so that they approach the tower more slowly.
*   Dodger: Automatically uses blink, if available, at times when it saves you from an enemy hook or ability.
