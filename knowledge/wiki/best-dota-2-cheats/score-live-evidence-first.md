## Score live evidence first

Start with the product’s current status page. Record the last check date, the Dota 2 build named, supported Windows versions and the channel used for updates. A green badge without a date is weak evidence. A temporary “updating” state is more credible than an instant promise after a major patch.

Then check whether the listing explains the exact modules you would use. “Full ESP” and “all heroes” do not tell you scope, triggers or exclusions. The [how Dota 2 cheats work guide](https://dota2cheat.com/guides/dota-2-cheats-work) helps translate feature labels into data and input questions.

Separate visible information from hidden-data claims.
