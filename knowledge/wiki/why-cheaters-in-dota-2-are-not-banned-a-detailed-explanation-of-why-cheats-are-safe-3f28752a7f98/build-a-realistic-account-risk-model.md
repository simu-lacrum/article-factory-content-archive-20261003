## Build a realistic account-risk model

Start with the value of the Steam account, inventory and match history. Add the chance of malware, credential loss, software downtime and permanent enforcement. Then ask whether the intended feature is worth the combined downside.

If any seller minimizes those consequences, treat that as a trust signal. Read the [VAC and Vanguard anti-cheat architecture explainer](https://cheatsgaming.com/games/dota-2/vac-vs-riot-vanguard-dota-2-lol-anti-cheat) for a careful system-level distinction, or return to the [Dota 2 cheat risk resource page](https://cheatsgaming.com/games/dota-2).
