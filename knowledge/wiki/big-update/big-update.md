Title: BIG UPDATE

Published Time: 2026-08-25

Markdown Content:
The biggest update in the history of the project. It brings a **new renderer**, a **new menu** and unlimited customisation. **~95% of the functionality** has been rewritten or touched in some way.

The update covers all of our games. For now you can only try it in Deadlock — over the coming week we plan to retire every older version, leaving only the new one.

[Video 10](https://octarinecore.cc/assets/images/blog/big-update/menu-tour.mp4)
*   Absolutely every element can be changed.
*   The menu resizes however suits you: make it compact so it doesn't cover objects or get in the way while you set things up. Every element inside adapts to the new size automatically.
*   The main menu can sit on top, to the side, be hidden, or be given a size of its own.
*   Endless themes: you can set up different ones for the world, the panels or the menu itself.
