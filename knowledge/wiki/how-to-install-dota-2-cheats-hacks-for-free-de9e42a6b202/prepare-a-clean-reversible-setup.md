## Prepare a clean, reversible setup

Close Dota 2, remove incompatible old versions and record any folders, services or drivers the installer says it will add. Create backups of personal configuration. Keep the uninstall instructions available before the first launch.

Do not disable security controls globally or permanently. If software requires an exception, understand its exact path and consequence. An unexplained request for broad administrator access is a reason to stop.
