### 10.5. Актуальные игровые термины 2026 — не путать в статьях

| Термин | Что значит | Контентное применение |
| --- | --- | --- |
| Facet / аспект | Выбор варианта стиля героя во время strategy time; влияет на роль, билд и силу героя | Патч/мета-гайды, hero guides, MetaPicker topics |
| Innate / врождёнка | Встроенная способность героя, активная с начала игры или меняющая базовую способность | Объяснять, почему старые билды устарели |
| Tormentor / Терзатель | Объект карты, связанный с shard/командной экономикой и fight timing | Vision, map awareness, support macro |
| Wisdom / Shrine of Wisdom | XP-объект/механика карты; важно для саппортов и early rotations | Support guides, timing guides |
| Lotus / Lotus pool | Объект на линии/карте, дающий sustain value | Lane guide, support/offlane articles |
| Watcher | Vision/objective map элемент | MapHack/VBE/vision explainers |
| Smoke / смок | Smoke of Deceit; ключевой инструмент gank/vision | Hidden spells, smoke detection, support macro |
| Glyph / глиф | Glyph of Fortification; меняет high ground/push timings | Patch/meta и macro-гайды |
| High ground | Заход на базу; часто решает late game | MMR climb, throw/comeback articles |
| Last known position | Последнее известное место врага | Корректное объяснение Partial MapHack |
| VBE / Visible by Enemy | Индикатор, что героя видит враг | Одна из лучших feature-specific SEO тем |
| Stream proof | Скрытие визуалов/оверлеев от OBS/stream output | Booster/streamer content |
| Humanizer | Слой, делающий действия scripts похожими на человеческий input | Safety explainers; без кода и private implementation |
| Game ban vs VAC ban | Разные типы отметок в Steam/profile context | Smurf/account-risk articles |
| Hidden pool / скрытый пул | Комьюнити-термин для плохого matchmaking/penalty ощущения | Viral RU/EN debate; не выдавать как доказанную механику без оговорок |

**Правило:** если термин относится к текущей карте/патчу (`facet`, `innate`, `tormentor`, `wisdom`, `lotus`, `watcher`), перед публикацией гайда проверять актуальную формулировку в patch notes или на Dota wiki/Dotabuff/Stratz. Если термин относится к рынку читов (`VBE`, `Humanizer`, `MapHack`, `stream proof`), проверять в базе Melonity/каналах продукта.
