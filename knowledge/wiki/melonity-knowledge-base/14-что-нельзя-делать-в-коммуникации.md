## 14. ЧТО НЕЛЬЗЯ ДЕЛАТЬ В КОММУНИКАЦИИ

| Делать | Не делать |
| --- | --- |
| **В SEO-контенте — обязательно использовать `cheat`, `hack`, `чит`, `хак`** как ключевые слова в H1/H2/первых параграфах/мета-тегах | Заменять SEO-ключи `cheat`/`hack`/`чит`/`хак` на «assistant»/«помощник» — это убивает органический трафик |
| Soft-sell в комьюнити-постах через ценность и комьюнити | Агрессивные «BUY NOW!!!» с капсом в каждом сообщении |
| Уважать пользователя как «своего» | Снобизм, обращение «школьник», «днище» |
| Использовать `cheat`, `hack`, `чит`, `хак` свободно в SEO/YT/постах. В премиум-визуале сайта (hero-section, баннеры) — допустимо смешивать с «assistant»/«scripts platform» | `aimbot` в Dota-контексте (FPS-термин), `exploit`, `trojan`, `virus`, `crack` (НЕ ключи и подрывают доверие) |
| Реалистично говорить о защите: «industry-leading protection», «6 лет проверенной работы», «multi-layer Humanizer», «undetected с 2020» | Обещать «100% защита от бана», «гарантированно не забанят» — юридически опасно |
| Подсвечивать ценность V8 API, Humanizer, MapHack 2.0, Stream Proof | Соревноваться по «количеству функций» (200 vs 500 — это спор, который мы не выиграем) |
| Активный саппорт и компенсация простоя | Игнор, отписки в стиле «no refund» без объяснений |
| Рекламировать через продакт-демо («посмотри как работает Auto-Combo с Humanizer») | Рекламировать через FOMO («только сегодня! последний день!») каждый день |
| Использовать слова `cheat`, `hack`, `чит`, `хак` в ALT-текстах картинок, hashtag'ах, file names скриншотов — это тоже SEO | Скрыв��ть ключевые слова в коде / делать их белыми на белом фоне (cloaking) — Google банит за это |
