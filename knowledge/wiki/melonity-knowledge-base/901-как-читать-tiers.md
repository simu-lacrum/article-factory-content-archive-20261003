#### 9.0.1. Как читать tiers

| Tier | Роль в контент-стратегии | Как использовать |
| --- | --- | --- |
| `core` | Прямой коммерческий / semi-commercial интент | Обзоры читов, сравнения, product-led статьи, FAQ, покупка/безопасность |
| `native` | Нативный educational интент | Гайды по Dota, мета, hero guides, behavior score, counterpick, patch reactions с мягкой интеграцией Melonity |
| `native-hero` | Hero-specific SEO | Статьи/видео по конкретным героям и связка с hero scripts, auto-combo, VBE, dodge, map awareness |
| `general` | Широкий Dota-трафик | Top-funnel, осторожно: много запросов нерелевантны покупке cheat, но полезны для web2.0-прогрева |
| `comp` | Конкуренты | Сравнения Melonity vs Umbrella/Octarine/Divine/Hake, tier lists, review pages |
| `nav` | Навигационные запросы | Обычно заняты брендами/официальными сайтами; использовать только как контекст |
