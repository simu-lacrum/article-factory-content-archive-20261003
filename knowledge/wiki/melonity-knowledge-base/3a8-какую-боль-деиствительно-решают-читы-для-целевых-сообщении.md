### 3A.8. Какую боль действительно решают читы (для целевых сообщений)

Это важно для UGC-контента, лендингов, креативов. **Не функции, а исходы**:

| Боль игрока | Что чит даёт | Best feature под боль |
| --- | --- | --- |
| Не растёт MMR годами | Информационное превосходство в каждом матче | MapHack + VBE + Hidden Spells |
| Тиммейты руинят / в скрытом пуле | Личный edge, не зависящий от team | Auto Dodge + Auto Combo + Last Hit |
| Сложные герои не получаются | Авто-комбо превращает любого героя в playable | Hero Scripts (Invoker, Arc Warden) |
| Нет идеального тайминга по cooldown'ам | Cooldown ESP + Auto Disabler | CD ESP + Manabars |
| Боюсь skillshot'ов из тумана | Hidden Spells + AOE radius | Show Hidden Spells |
| Хочется красивую игру (skins дорого) | Skin Changer открывает всё | Skin Changer + custom landscapes |
| Бустить — рисково / медленно | Stream Proof + HWID Spoofer | OBS Bypass + Spoofer |
| Скучно играть как все 10 лет | Camera Hack меняет восприятие игры | Camera Hack |
| Вечный фарм гриндом | Auto Last Hit + Stack Helper | Last Hit + Stack |
| Игра «не та, что 5 лет назад» | Custom skins, low poly map, retro feel | Skin Changer + Map mod |
