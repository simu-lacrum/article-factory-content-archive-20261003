#### Категория C: Supporting Scripts (вспомогательные)

Самая большая по количеству категория. Автоматизация и удобство.

| Скрипт | Что делает | Сложность реализации |
| --- | --- | --- |
| **Auto Last-Hit** | Точно добивает крипа когда HP = 1 хит, учитывая damage башни/крипов/героев + промахи | ★★★★★ (один из самых сложных — нужно симулировать damage chain) |
| **Auto Deny** | Так же, но для своих крипов | ★★★ |
| **Camera Hack** | Зум камеры колесом мыши + увеличение far clipping plane (`r_farz 18000`) — видно почти всю карту | ★★★★ (требует обхода `sv_cheats` ConVar) |
| **Auto Dodge** | Авто-уворот от Hook, стансов, Sun Strike — использует Blink, BKB, Linken's, Glimmer | ★★★★ (нужна prediction траектории и таймингов) |
| **Auto Pick / Auto Ban** | Авто-пик и бан выбранных героев в драфте | ★★ (простой) |
| **Auto Accept Match** | Принимает игру когда нашёлся матч | ★ |
| **Auto Use Items** | Авто-Tango, Salve, Magic Stick, Medallion | ★★★ |
| **Rune Snatcher** | Подбирает руну при приближении к ней | ★★ |
| **Tree Destroyer** | Авто-снос деревьев Tango/Quelling Blade в нужных точках | ★★★ |
| **Auto Push** | Контроль крипов на лайне для оптимального push'а | ★★���★ |
| **Kill Stealer** | Гарантированный kill через скиллы/предметы когда враг при смерти | ★★★ |
| **Stack Helper** | Перфектный стек camps в нужное время (53-я сек минуты) | ★★★ |
| **Ward Helper** | Подсказывает оптимальные точки для observer/sentry wards | ★★ (требует knowledge base карты) |
| **Auto Disabler** | Авто-stun/silence/hex при попытке врага скаст ультой | ★★★★★ |
| **Smart Block** | Block enemy creep aggro для лайн-control | ★★★ |
