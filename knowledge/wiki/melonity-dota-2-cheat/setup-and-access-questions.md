## Setup and access questions

Before creating an account, confirm the supported Windows version, the current Dota build, whether access begins at purchase or first activation, and the provider’s download channel. The plan should state duration, currency, final price and what happens during a patch-related pause. Do not infer these details from a video.

Use the [Dota 2 cheat installation guide](https://dota2cheat.com/guides/install-dota-2-cheats) for a clean, reversible setup. Never send Steam credentials, browser cookies or recovery codes to a provider. If an executable asks for broad administrator access or a permanent security exception without an explanation, stop and ask support through the authenticated channel.
