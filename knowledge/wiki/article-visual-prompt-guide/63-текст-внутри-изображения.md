### 6.3. Текст внутри изображения

Для Nano Banana Pro допускаются два производственных режима.

Режим A — text-in-image, если нужен короткий постерный заголовок:

- дать точную строку в кавычках;
- явно указать язык;
- указать регистр, количество строк, положение, начертание и цвет;
- запретить любой другой текст;
- просить сохранить каждую букву дословно;
- после генерации проверить орфографию, пропуски, лишние символы и переносы.

Режим B — art-first, если текст длинный, критичен для SEO/бренда или должен точно совпасть с версткой:

- попросить чистую безопасную зону без псевдотекста;
- сгенерировать иллюстрацию;
- наложить заголовок в редакторе;
- при локализации менять только слой текста.

По умолчанию для ветки A и для финальной веб-верстки использовать art-first. Для B-fidelity использовать text-in-image с точной строкой из 3–7 слов либо обязательно наложить заголовок вручную до сравнения с референсами. Нельзя оценивать пустую art-first B-заготовку как «похожую на референсы», потому что в исходной серии крупная типографическая масса является структурной частью кадра.
