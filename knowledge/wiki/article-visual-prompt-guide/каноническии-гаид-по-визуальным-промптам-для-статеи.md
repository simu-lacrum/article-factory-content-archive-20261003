# Канонический гайд по визуальным промптам для статей

`MANDATORY_SESSION_GUIDE: article-editorial-poster-v1`

Этот файл — обязательная проектная память, а не набор необязательных советов. Перед планированием статьи, созданием ТЗ, написанием черновика или подготовкой иллюстраций агент обязан пройти session bootstrap, прочитать этот файл полностью и использовать описанную ниже систему. Если задача затрагивает визуалы, промпты нельзя писать «с нуля по вдохновению»: они компилируются из смысла статьи, визуальной роли изображения, канона стиля и специфики целевой модели.
