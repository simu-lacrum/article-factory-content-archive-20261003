## 13. Универсальный шаблон для Nano Banana Pro

```text
Create [ASSET ROLE] for an editorial article titled “[WORKING TITLE]”.

Style routing: this is generated asset #[GENERATED_SEQUENCE_INDEX] in the current run. Use style branch [A — TACTILE INDUSTRIAL PRODUCT POSTER / B — WARM NARRATIVE EDITORIAL AD, SUBMODE B1/B2/B3]. Keep this branch dominant and do not blend it with the other branch.

Editorial thesis: [ONE FACTUAL SENTENCE]. The image must communicate [CORE CONFLICT OR TRANSFORMATION] within one second at thumbnail size.

Visual metaphor: represent [ABSTRACT SUBJECT] as [ONE PHYSICAL HERO OBJECT OR SCENE] that is [ONE CLEAR ACTION]. For branch A, make it a physically believable industrial-design prototype or tactile still life. For branch B, make it a warm, rounded narrative scene or single symbolic object with one everyday action; do not introduce industrial machinery, dark chassis, rails or fasteners.

Canvas and output: [ASPECT RATIO] [ORIENTATION], composed as a [1K/2K/4K] master. Keep [PERCENT] crop-safe margins. This asset will be used as [PLACEMENT].

Composition: reserve a clean, low-detail headline zone at [POSITION AND NORMALIZED AREA]. Place the hero at [POSITION], occupying roughly [PERCENT] of the frame. Use only one secondary signal element at [POSITION]. Allow [CONTROLLED CROP / NO CROP]. Maintain three levels of visual hierarchy at most.

Hero object: [SHAPE, SCALE, ORIENTATION, FUNCTIONAL DETAIL]. Use [MATERIAL 1] and [MATERIAL 2], with physically correct thickness, seams, contacts, refraction and reflections. Make it tactile and manufacturable, not an abstract blob.

Environment: [MINIMAL SET]. Include only [SUPPORTING PROPS], each serving the story. No decorative clutter.

Camera: [ANGLE], [LENS FEEL], [PERSPECTIVE], focus on [FOCAL TARGET], [DEPTH OF FIELD].

Palette: background [COLOR/HEX AND ROLE], hero [COLOR/HEX AND ROLE], secondary signal [COLOR/HEX AND ROLE], typography [COLOR]. Mapped brand color: [Cluster #635FD5 / Melonity #FF1469 / none]. For branch A, assign it to [ONE SEMANTIC ELEMENT], covering about [3–8%] of the frame and never using it as a global wash. For branch B, use it as the dominant field replacing the reference's yellow/amber background, covering roughly [35–70%] of the frame; preserve warm secondary objects and do not leave yellow as the main field. Keep 80–90% of the image inside the declared color roles.

Lighting: [SOURCE, DIRECTION, HARDNESS], creating [SHADOW TYPE]. Preserve readable material definition and restrained highlights. No global neon glow.

Typography mode: [ART-FIRST OR TEXT-IN-IMAGE]. [IF ART-FIRST: Keep the headline zone completely empty: no letters, glyphs, pseudo-text, logos or interface labels.] [IF TEXT-IN-IMAGE: Render exactly “[EXACT COPY]” in [LANGUAGE], [CASE], [LINES], bold geometric condensed sans-serif, at [POSITION]. No other text anywhere. Preserve every character exactly.]

Reference fidelity: target at least 4/5 agreement with the active branch references in layout silhouette, warm/light palette, shape language, depth treatment and typography mass. For branch B, two uploaded files are mandatory.

Reference roles: Image A, file [PATH/NAME], is only the composition reference from style branch [A/B]: use [EXACT PROPERTY]. Image B, file [PATH/NAME], is only the render/palette/typography reference from the same branch: use [EXACT PROPERTY]. Do not reproduce their logos, text, people, product identity, objects or exact layout. Do not import visual language from the inactive style branch.

Editorial character: direct, intelligent, playful, materially convincing, controlled surrealism, modern technology product poster. It must not look like generic gaming key art.

Do not include: [SCENE-SPECIFIC FAILURES], game logos, recognizable copyrighted characters, weapon glamour shots, cyberpunk neon, holographic HUD clutter, random code, fake statistics, extra text, watermarks as visible design elements, malformed controls, impossible shadows or more than one hero object.

If constraints conflict, prioritize: 1) editorial thesis, 2) clean hierarchy, 3) headline safe zone, 4) hero silhouette and physical plausibility, 5) palette, 6) minor surface detail.
```
