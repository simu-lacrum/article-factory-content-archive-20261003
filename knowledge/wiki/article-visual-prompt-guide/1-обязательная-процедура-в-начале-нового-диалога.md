## 1. Обязательная процедура в начале нового диалога

1. Запустить `python -m article_factory graph bootstrap` из корня проекта.
2. Убедиться, что отчет показывает `PASS`, покрытие узлов `100%` и покрытие связей `100%`.
3. Полностью прочитать `memory/graph/SESSION_BOOTSTRAP.md` и все файлы из раздела `Required reading`.
4. Для статьи сначала извлечь ее тезис, поисковый интент, факты и ограничения; только потом выбирать визуальную метафору.
5. Для каждого изображения заполнить минимальный контракт промпта из раздела 18.
6. Для Nano Banana Pro явно назначить роль каждому приложенному референсу и не смешивать функции изображений.
7. Присвоить каждому generated image последовательный номер и стилевую ветку: нечетные слоты — новая B, четные — исходная A. Реальные скриншоты последовательность не сдвигают.
8. Применить брендовый цвет по продуктовой карте: Cluster — `#635FD5`, Melonity — `#FF1469`. В ветке A это малый сигнальный акцент; в ветке B он заменяет доминирующее желто-янтарное поле референса.
9. Перед отдачей промпта провести проверку по 100-балльной шкале. Промпт ниже 80 баллов переписать.

Session bootstrap программно обходит все узлы и все связи графа, включая изолированные компоненты. Чтение только этого файла, только Mermaid-экспорта или случайной выборки узлов не заменяет полного обхода.
