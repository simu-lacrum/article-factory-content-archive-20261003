## 18. Минимальный контракт промпта

Ни один финальный промпт не считается готовым, пока явно не содержит:

- `asset_role` — где и зачем используется изображение;
- `generated_sequence_index` — порядковый номер среди generated assets текущего run;
- `style_branch` — A либо B с B1/B2/B3 при необходимости; значение должно соответствовать четности индекса;
- `article_thesis` — один фактический тезис;
- `visual_metaphor` — физический перевод тезиса;
- `single_hero` — один доминирующий объект/сцена;
- `aspect_ratio` — поддерживаемая пропорция;
- `composition` — зоны текста, героя и акцента;
- `palette_roles` — фон, герой, сигнал;
- `brand_color_role` — Cluster `#635FD5`, Melonity `#FF1469` или обоснованное `none`; для A указать один малый носитель и 3–8%, для B — доминирующее поле и 35–70%;
- `materials` — минимум один конкретный материал;
- `camera` — ракурс и перспектива;
- `lighting` — направление и качество света;
- `typography_mode` — `art-first` или `text-in-image`;
- `reference_roles` — функция каждого приложенного изображения;
- `reference_fidelity` — для B минимум два фактически приложенных файла и цель 4/5 по layout, palette, shape language, depth, typography mass;
- `constraints` — сюжетно-специфические запреты;
- `priority_order` — порядок разрешения конфликтов;
- `model_target` — `Nano Banana Pro / gemini-3-pro-image` по умолчанию;
- `output_size` — 1K/2K/4K с заглавной K.

Если хотя бы один пункт отсутствует, промпт остается черновиком.
