## Choose the correct cosmetic workflow

If you want to create an item for submission, use Valve's Workshop tools and published requirements. If you want a cosmetic visible as part of your Steam inventory, obtain it through supported game and marketplace flows. If a third-party program promises local replacement without ownership, treat it as an unofficial modification.

The [Dota 2 Workshop creator requirements](https://www.dota2.com/workshop/requirements) explain supported authoring limits. They do not authorize a loader that modifies a running game.
