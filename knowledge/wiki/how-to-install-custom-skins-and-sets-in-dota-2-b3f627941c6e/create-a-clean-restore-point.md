## Create a clean restore point

Before changing files, close Dota 2 and record the current installation state. Keep a list of every folder the tool will touch. Back up user-created configuration separately, because a general game-file repair may not restore your preferred settings.

Do not download a bundle whose contents are hidden behind an executable with no manifest. Cosmetic archives should make their file purpose clear. Never provide a Steam password, session cookie or recovery code to an installer.
