## Update evidence and access status

Anchor the comparison to the current Dota build named by each provider. Old clips can explain a control, but they cannot prove that the module still works today. Record the listing date, update status and supported build next to each feature claim.

Both products are third-party tools with their own setup and support requirements. Read the [Dota 2 detection guide](https://dota2cheat.com/guides/dota-2-cheat-detection) when you need broader platform context, then return to the live listings for current plans and modules.

![Image 4: Dota 2 build helper interface for a product comparison](https://dota2cheat.com/assets/dota2/dota2-41ba5d7f0b2e46bd1f78e208.webp)

Use a current build check rather than a static product ranking.
