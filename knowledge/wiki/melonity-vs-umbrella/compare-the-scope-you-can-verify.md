## Compare the scope you can verify

Start with a two-column sheet. For each product, record the date checked, supported Windows version, named Dota build, active hero modules, visual functions, utility tools and documented exclusions. If a page says “all heroes” without a list or date, write “not specified”. Do not turn a forum comment or an old video into a fact.

Melonity is presented in the preserved interface as a broad script platform with hero modules, visual panels and utility controls. Umbrella is shown as a more compact menu in the available material. Those are observations about the supplied media, not a current feature guarantee; the live listings must confirm what is available now.
