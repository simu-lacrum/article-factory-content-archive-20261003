## Identify the artifact

A text file can be read before use. A custom-game or bot package belongs to a supported creator environment. A macro profile changes device input. A closed loader is an executable that can install more than its page describes. The [Dota 2 scripts guide](https://dota2cheat.com/guides/dota-2-scripts-guide) explains those categories so a generic “script” label does not hide the environment.

Record the file type, required runtime, supported Dota build and intended mode. If a page cannot tell you whether the download is source code, a configuration or a binary, stop before running it. A password-protected archive prevents basic inspection and gives you little accountability.
