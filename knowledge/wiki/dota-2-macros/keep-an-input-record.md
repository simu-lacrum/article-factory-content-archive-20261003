## Keep an input record

Save the profile name, device software version, timing values and intended practice mode. If a driver update changes the order or delay, you can compare the new behavior with the old record instead of guessing. Remove profiles you no longer use, especially those that activate automatically when a game process appears.

Review the reset path on a schedule, not only after a failure. A profile that is easy to disable in the device software is less likely to run in the wrong application. Keep a normal profile selected before browsing, streaming or joining an event, and make the game-specific profile opt-in rather than automatic.
