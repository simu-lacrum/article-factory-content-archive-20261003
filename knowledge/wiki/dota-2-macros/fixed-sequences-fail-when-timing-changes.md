## Fixed sequences fail when timing changes

A fixed combo assumes stable delays. Network latency, cast point, turn rate, disables, spell immunity and target movement can shift every later input. Long sequences are especially brittle because one interruption changes the rest. A profile that works in a clean demonstration may fail as soon as a target moves or an order is cancelled.
