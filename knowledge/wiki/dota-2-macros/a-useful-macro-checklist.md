## A useful macro checklist

*   How many inputs does one activation send?
*   Does it read or react to game state?
*   Can timing be changed without hidden software?
*   Does it install a service, driver or startup entry?
*   Is there a complete reset and removal path?
*   Are platform and event rules stated clearly?
