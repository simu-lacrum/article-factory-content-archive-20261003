## Start with the supported cosmetic path

Owned Dota items and approved Workshop submissions use Valve's supported systems. A local skin changer may replace assets, patch files or interact with the running client. The visual result can be similar while the delivery method is fundamentally different. Use Valve's Workshop requirements to understand the creator route, but do not treat a third-party page's “Workshop skins” label as proof that its installer follows it.
