## Separate evidence from marketing

A useful review records the exact claim next to the evidence that supports it. A screenshot supports an interface description. A release note supports a change claim. A documented uninstall supports a removal claim. None of these proves future compatibility or account status. Keeping those statements separate makes the article easier to update when a product page changes.

Also check whether the support route can answer a technical question without asking for a Steam login. Good support can identify a file version, a Windows requirement or a rollback step. It should not need control of the account that owns the game.

Do the same with security language. A signed installer, a clean scan and a documented publisher each answer a different question. None is a substitute for the others, and none changes Valve's treatment of a third-party modification that provides an advantage. A careful article keeps the technical review and the account decision visible side by side.

Keep those records private: screenshots of license details, paths or account identifiers should never become public support posts.
