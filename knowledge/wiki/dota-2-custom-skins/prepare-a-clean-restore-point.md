## Prepare a clean restore point

Close Dota 2 before changing files. Note the current game build, the source and version of the package, and every folder the instructions mention. Keep personal configuration backups separate from the game directory. Do not open an executable whose contents and publisher are hidden behind a password-protected archive.

![Image 3: Dota 2 custom skins configuration screen](https://dota2cheat.com/assets/dota2/dota2-73b979f34faddcbb8312d753.webp)

Never give an installer your Steam password, browser cookie, email code or recovery code. If it asks you to disable antivirus, firewall or Secure Boot globally, stop and reassess. An explanation of a narrow, temporary requirement is different from a request to remove account and system protections.
