## Adaptive automation changes the category

A system that chooses targets, waits for conditions or reacts to enemy spells uses logic beyond replayed inputs. It may be sold as a “smart macro,” but buyers should evaluate it as a script: data source, supported heroes, configuration, false triggers and update requirements.

See the [Dota 2 automation and script taxonomy](https://cheatsgaming.com/games/dota-2/dota-2-cheats-scripts-explained-2025-all-about-dota-hacks-82ff479af22d) for those categories.
