## Fixed sequences and timing failure

A fixed combo assumes stable delays. Dota introduces network latency, turn rate, cast point, animation changes, disables, spell immunity and target movement. One interruption can shift every later input.

Long sequences are especially brittle. A macro cannot reconsider the fight unless it reads game state, at which point it is closer to adaptive script automation.
