## File and permission risk

Ask exactly which files, services or drivers are added. An installer that requests administrator access should explain the need before execution. A package should not require your Steam password, browser session, mobile confirmation or recovery code.

Security scanners can catch known threats, but a clean result is not a guarantee. Publisher identity, signed releases, a reproducible version trail and a complete uninstall path are separate signals.
