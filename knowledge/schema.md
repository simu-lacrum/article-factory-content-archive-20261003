# Knowledge Schema

Эта папка хранит wiki-слой поверх сырьевых источников. Его можно читать напрямую из Obsidian, Git, Codex или MCP-памяти.

## Типы данных

- `raw` - исходники без переписывания: CSV, markdown, тексты из ссылок, будущие PDF.
- `wiki` - нарезанные и нормализованные страницы из исходников.
- `semantic_cluster` - поисковый кластер из CSV.
- `topic_idea` - статья-кандидат с оценкой, ключами, планом и рекламной интеграцией.
- `evidence_pack` - набор фактов перед генерацией статьи.

## Правила

1. Не писать статью без evidence pack.
2. Не выдумывать свежие факты: патч, мета, цены, античит-волны, статус функций.
3. Отделять образовательную часть от рекламной интеграции.
4. Не давать операционные инструкции по обходу античита, эксплуатации уязвимостей или реализации чит-функций.
5. После публикации добавлять статью в `published/articles.csv`, чтобы не дублировать темы.
