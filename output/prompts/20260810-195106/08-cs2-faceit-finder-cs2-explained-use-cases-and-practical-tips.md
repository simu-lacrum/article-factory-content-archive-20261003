### How does VAC work? There are two main types of anti-cheats in games: server-side and client-side, the latter having several levels of access. VAC has a client module that is responsible for checking the integrity of game files, as well as a server module that checks what orders you send to the server with mouse clicks, etc. There are a whole bunch of such checks, which cannot be listed here. There are also kernel anti-cheats that run directly in the BIOS, such as Vanguard or Faceit. These are often cited as the best anti-cheats, but their design is also their biggest drawback. Unlike VAC, which only monitors the game itself, these anti-cheats have full access to the files on your computer. This means that Vanguard, for example, could potentially access your data if it wanted to. There are no documented cases of this happening, but there are warning signs.
