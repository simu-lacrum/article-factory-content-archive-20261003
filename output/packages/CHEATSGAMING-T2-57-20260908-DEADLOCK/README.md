# CheatsGaming Deadlock article package

This package contains the 15 Deadlock articles from briefs CG-028 through CG-042. Article language is English.

## Contents

- `md/` — canonical Markdown sources with SEO front matter, internal-link suggestions, and complete image-production notes.
- `html/` — self-contained browser files. Open one and press **Copy formatted article** to copy only the public article as rich HTML for JustPaste.me.
- `index.html` — package navigator with links to every Markdown and HTML file.
- `references/article-editorial-warm-story-v1/` — the persistent source images named by branch-B generation prompts.
- `manifest.json` — article IDs, slugs, word counts, and artifact paths.
- `QUALITY-REPORT.md` — deterministic content, SEO/GEO, safety, visual-contract, and export checks.
- `SHA256SUMS.txt` — file integrity hashes.

## Publishing workflow

1. Open `index.html`.
2. Choose an article and open its copy-ready HTML file.
3. Review volatile statements on publication day: Deadlock update context, product status, feature/hero coverage, price, trial terms, compatibility, and support details.
4. Press **Copy formatted article** and paste into JustPaste.me.
5. Produce the cover and supporting visual from the notes below the article. Those notes are deliberately excluded from the copied body.
6. Add the final image at each declared placement, confirm alt text and caption, and test mobile cropping.

## Editorial and safety boundary

The set is evidence-led and high-level. It does not contain installation steps, exact automation settings, trigger logic, detection internals, bypass/evasion instructions, mirrors, or security-warning workarounds. Marketing statements are treated as source claims, not independent facts. No article promises safety, permanent compatibility, “undetected” status, or a no-ban outcome.

## Visual system

Branch A uses exact Cluster `#635FD5` as a small 3–8% semantic accent. Branch B uses it as the dominant 35–70% field replacing yellow/amber and names two packaged reference files with distinct roles. Supporting screenshots and factual diagrams do not consume a generated index.
