# Как вставлять статьи в Tumblr с форматированием

Обычный `Ctrl+C` → `Ctrl+V` из исходного `.md`-файла не сохраняет оформление, потому что редактор Tumblr по умолчанию работает в режиме Rich text и воспринимает Markdown-разметку как обычный текст. В исходниках также есть служебный YAML и скрытые комментарии для производства иллюстраций — их публиковать не нужно.

## Рекомендуемый способ: режим Markdown

1. На сайте Tumblr создайте текстовый пост.
2. Нажмите значок шестерёнки в правом верхнем углу редактора.
3. В поле **Text editor** выберите **Markdown**.
4. Откройте нужный файл из папки `markdown` в этом комплекте.
5. Выделите всё (`Ctrl+A`), скопируйте (`Ctrl+C`) и вставьте в редактор (`Ctrl+V`).
6. Откройте предпросмотр: заголовки, жирный текст, списки и ссылка должны быть оформлены автоматически.

Это чистые публикационные версии: YAML, комментарии `IMAGE_SLOT` и раздел `Internal-link suggestions` уже удалены.

## Запасной способ: режим HTML

1. В том же меню шестерёнки выберите **HTML**.
2. Откройте соответствующий файл из папки `html` обычным текстовым редактором.
3. Скопируйте весь код и вставьте его в поле Tumblr.
4. Проверьте предпросмотр перед публикацией.

HTML-файлы содержат только базовые теги заголовков, абзацев, списков, выделения и ссылок. Скриптов, стилей и сложной разметки в них нет.

## Если нужен именно Rich text

Откройте HTML-файл в браузере, выделите отрисованный текст на странице и скопируйте его в Rich text. Этот путь менее надёжен: браузер и Tumblr могут по-разному перенести интервалы. Для этих статей режим Markdown — основной.

Официальная справка Tumblr: [Writing Posts](https://help.tumblr.com/knowledge-base/writing-posts/) и [Using and Formatting Text](https://help.tumblr.com/using-formatting-text/).

Исходные статьи в `output/articles/20260810-201057` не изменялись.
