## Check the operating system first

The live listing displayed “Windows 11 64-bit / Windows 10 64-bit” in the system field. Its longer description excluded Windows Insider Preview builds and said macOS was unsupported.

That creates three fast stop conditions:

- you use macOS;
- your Windows installation is an Insider Preview build;
- the seller cannot confirm that the current product supports your specific environment.

Do not reinterpret a Windows label as “every Windows configuration.” Drivers, security software, virtualization, game updates and hardware differences can affect a third-party tool. The right pre-purchase question is not “Will this definitely work?” It is “What exact environment does the current listing support, and what happens if my unused key is incompatible?”

## Separate game compatibility from system compatibility

System compatibility means the software is intended for a stated operating system. Game compatibility means the current product build works with the current game build. These are different claims.

A Windows 11 badge can remain true while a fresh Dota 2 update temporarily breaks a feature. Conversely, a current product update does not prove it works on an unsupported operating system. Record both dates when possible: the seller's product check and the newest product update evidence.

The page showed “Checked 2026-09-09” when reviewed. Treat that as the seller's dated snapshot, not a lifetime status.

## Understand automatic key delivery

The listing says that after confirmed payment, the reserved key appears automatically in the Orders page. It also says the buyer receives an activation link and setup instructions for the selected access period.

Before paying, verify:

1. the selected duration;
2. the final payable amount and payment provider;
3. the account where Orders will be available;
4. the delivery wording shown at checkout;
5. the published route for a missing or invalid unused key.

Take a clean record of the order reference and confirmation. Do not post the license key publicly or send it to an unrelated support account.

## Know which support route handles which problem

The product page separates order issues from technical questions. It publishes a CheatsGaming email for order, payment and automatic-delivery problems. It also points technical configuration questions to the official Melonity support bot and displays daily support hours from 08:00 to 00:00 Moscow time.

That separation is useful. A reseller can verify an order, while the developer is better placed to answer product-specific questions. Neither route needs your Steam password, OAuth code or recovery code.

If someone asks for those credentials, stop. An order reference and non-sensitive environment details should be enough to identify the transaction and start diagnosis.
