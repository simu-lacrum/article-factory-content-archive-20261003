# Melonity SEO Cluster Map for English-Friendly Articles

Цель: подобрать темы не "из головы", а от кластеров `Семантическое_ялро_дота.csv`, с учетом трех фильтров:

1. можно естественно встроить Melonity;
2. есть шанс подниматься в выдаче без прямой войны по ВЧ `dota 2 cheat`;
3. тема переносится в англоязычную выдачу и не дублирует уже написанные материалы про MapHack и прямое `Melonity vs Umbrella`.

## Что не брать в первую очередь

| Кластер / тема | Почему не приоритет |
| --- | --- |
| `CORE: читы dota 2` в лоб: `dota 2 cheat`, `чит дота 2`, `купить чит dota 2` | KD 8, выдача занята серыми коммерческими сайтами и реселлерами. Лучше использовать как вторичные ключи внутри более узких статей. |
| Прямой `MapHack in Dota 2` | Уже написано. Можно брать только соседние углы: Courier MapHack, particle info, map awareness, но не повторять основную статью. |
| Прямой `Melonity vs Umbrella` | Уже написано. Кластер Umbrella стоит добирать через `cfg`, `setup`, `promocode`, `not launching`, `alternatives`, а не через еще одно сравнение. |
| Общие hero-гайды `Pudge guide`, `Invoker guide`, `Arc Warden guide` | В CSV KD 7, выдача забита Dotabuff, Cybersport, YouTube. Лучше заходить через `macro`, `script`, `auto combo`, `AHK`, где выдача старее и слабее. |
| `Dota 2 ranks/MMR table` | Большой трафик, но KD 8 и много инфо-доменов. Лучше использовать связку с boost/account/behavior/hidden pool. |
