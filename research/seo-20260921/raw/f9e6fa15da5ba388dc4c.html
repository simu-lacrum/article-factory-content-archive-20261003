What a script is in Umbrella

A script is a set of automatic actions bound to one button. Unlike a macro (a dumb key recording), a script reads the game state: enemy positions, cooldowns, HP, active effects. It fires only when the conditions are perfect.

Examples:

  • Invoker auto-combo — you bind one button: Tornado → EMP → Meteor → Deafening Blast in the perfect order.
  • Pudge hook angle — you aim the cursor roughly — the script computes the angle with prediction.
  • Lina auto-ult — ultimates an enemy when HP is below the ultimate's damage.
  • Armlet abuse — auto toggle on/off of Armlet for +HP manipulation.

FAQ

Are scripts the same as macros?

No. A macro is a dumb key recording with no context awareness. A script reads the game state and fires only when the conditions are met. So a script is far more effective and less noticeable.

Can you use scripts in ranked?

Technically — yes, the cheat works in any mode. Ethically and by Valve's rules — it's a violation. Use at your own risk, with the spoofer.
